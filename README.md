# Graded Exercise 2

Java implementation of:

- Exercise 2.0 — Loan Class
- Exercise 2.1 — BMI Class
- Exercise 2.2 — Course Class

## Requirements

Java JDK 8 or later.

## Compile

From the project root:

```bash
javac -d out src/*.java
```

## Run

```bash
java -cp out Main
```

## Exercises

### Exercise 2.0 — Loan
Implements the Loan class with:
- Annual interest rate
- Number of years
- Loan amount
- Loan creation date
- Constructors
- Getters/setters
- Monthly payment
- Total payment

### Exercise 2.1 — BMI
Implements:
- Name
- Age
- Weight
- Height
- Two constructors
- BMI calculation
- BMI status

### Exercise 2.2 — Course
Implements:
- Course name
- Student array
- Dynamic array expansion
- Add student
- Drop student
- Get students
- Student count
